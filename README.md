# rafsan.thunderapps.xyz

Personal portfolio of Rafsan Nazmul, iOS engineer.

Plain HTML, CSS and JavaScript with no build step and no frameworks. Hosted on GitHub Pages (see `CNAME`).

- `index.html` holds all the content
- `css/style.css` holds the design tokens (colors, type, spacing) at the top, with light and dark themes
- `js/main.js` adds small extras: active nav link, the "Copy address" button, the footer year
- `img/` holds the headshot (location data removed), favicon and social preview card

To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.
